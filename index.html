01. Redes Sociales Integradas

OpusBot facilita la gestión simultánea de contenido en las siguientes plataformas mediante APIs oficiales:

Instagram

Graph API

TikTok

Upload API

YouTube

Data API v3

Video API

§1 Aceptación de Términos

Al acceder y utilizar OpusBot, el usuario reconoce haber leído, comprendido y aceptado vincularse por estos Términos y Condiciones, así como por las políticas de privacidad de cada plataforma de red social integrada. El uso del servicio constituye aceptación plena e incondicional de todas las disposiciones aquí contenidas.

§2 Descripción del Servicio

OpusBot es una plataforma de gestión y automatización que permite a los usuarios:

  • → Programar y planificar contenido multimedia para múltiples plataformas
  • → Centralizar la publicación de videos en TikTok, Instagram, YouTube y Facebook
  • → Gestionar conexiones API de manera unificada
  • → Almacenar y organizar contenido en la nube (Neural Bank)

§3 Cuenta de Usuario y Conexiones

El usuario mantiene control total sobre sus conexiones con redes sociales. Tiene derecho a:

Bloqueo de Conexiones

El usuario puede bloquear o desconectar cualquiera de sus cuentas de redes sociales en cualquier momento desde la configuración de la plataforma.

Anclar Cuentas

Función de anclado disponible para priorizar la publicación en plataformas específicas según estrategia del usuario.

§4 Programación y Planificación de Contenido

OpusBot permite la planificación anticipada de publicaciones. El usuario comprende y acepta que:

  • 04.1 Las publicaciones programadas se ejecutarán automáticamente según la fecha y hora especificadas
  • 04.2 El usuario es responsable del contenido programado y sus implicaciones legales
  • 04.3 OpusBot no modifica ni edita contenido automáticamente sin autorización del usuario
  • 04.4 Los fallos en la publicación por causas técnicas de las APIs externas no son responsabilidad de OpusBot

§5 Propiedad Intelectual y Contenido

El usuario conserva todos los derechos sobre el contenido cargado en OpusBot. Al utilizar el servicio:

  • → El usuario garantiza que posee todos los derechos necesarios sobre el contenido
  • → OpusBot actúa únicamente como intermediario técnico para la publicación
  • → El contenido almacenado en Neural Bank permanece bajo propiedad exclusiva del usuario

§6 Limitación de Responsabilidad

OpusBot se proporciona "tal cual" sin garantías expresas o implícitas. No nos hacemos responsables por pérdidas de datos, interrupciones del servicio, o cualquier daño directo, indirecto, incidental o consecuente derivado del uso de la plataforma, incluyendo pero no limitándose a acciones tomadas por las plataformas de redes sociales sobre el contenido publicado.

§7 Modificaciones del Servicio

OpusBot se reserva el derecho de modificar, suspender o discontinuar cualquier aspecto del servicio en cualquier momento. Los cambios serán comunicados a través de la plataforma. El uso continuado del servicio después de cualquier modificación constituye aceptación de los nuevos términos.

§8 Políticas de Plataformas de Terceros

El uso de OpusBot está sujeto a las políticas y términos de servicio de las plataformas de redes sociales conectadas:

TOS-01 Términos de TikTok TOS-02 Términos de Instagram TOS-03 Términos de YouTube TOS-04 Términos de Facebook

§9 Privacidad y Protección de Datos

OpusBot recopila información mínima necesaria para el funcionamiento del servicio. Los tokens de acceso a redes sociales se almacenan de forma encriptada y nunca se comparten con terceros.

Datos recolhits: Correo electrónico de Google OAuth, tokens de API encriptados, metadatos de publicaciones.
